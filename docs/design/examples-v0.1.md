# Pyccha v0.1 コード標本集

この文書は、Pyccha の語感と文法を実際のコード断片で確認するための標本集です。

2026-09-29 に E001〜E014 を上から再確認し、v0.1 の最初の parser / transpiler に渡せるところまで判定しました。

北九州弁そのものの記録は [北九州弁ノート](../dialect/kitakyushu.md)、言語設計は [v0.1 文法ワークベンチ](grammar-v0.1.md) を参照します。

## 今回の判定原則

- 方言として自然な表現と、Pyccha の構文として使う判断を分ける。
- 方言化すると不自然になる演算は、記号のまま残してよい。
- v0.1 は曖昧さより、読めること・実装できることを優先する。
- `〜ん` は何にでも付く万能接続にはせず、比較・否定の述語を `やったら` へつなぐ形として扱う。
- `やけん` と `っちゃ` は重要な北九州弁だが、v0.1 の予約語にはしない。

---

## E001 まず一言しゃべる

**ねらい**: 最小の出力構文。

```text
"こんにちは" っちゆう
```

**判定**: 採用候補

- v0.1 の標準出力は `<式> っちゆう` を第一候補とする。
- 自然会話の `〜っち言う` と完全に同じ意味だと主張するのではなく、引用・発話の語感を借りた Pyccha の構文として採用する。

---

## E002 変数を作ってしゃべる

**ねらい**: 代入と出力の組み合わせ。

```text
名前 = "山田"
名前 っちゆう
```

**判定**: 採用候補

- 代入は `=` のままにする。
- 方言化のためだけに代入文を長くしない。

---

## E003 条件分岐

**ねらい**: `もし / やったら / ちごうたら / おしまい` の並びを確認する。

```text
名前 = "山田"

もし 名前 == "山田" やったら
    "本人っちゃ" っちゆう
ちごうたら
    "誰なん？" っちゆう
おしまい
```

**判定**: 採用候補

- v0.1 では `もし` を必須にする。自然会話上の必須性ではなく、条件節の開始を明確にするための設計判断。
- else は `ちごうたら` を採用候補とする。
- block 終端は `おしまい` を採用候補とする。
- 等値比較を無理に `〜と同じ` へ伸ばさず、`==` を使う。

---

## E004 3回くりかえす

**ねらい**: 回数指定ループ。

```text
3回くりかえす
    "まだやるん？" っちゆう
おしまい
```

**判定**: 採用候補

- `N回くりかえす` を v0.1 の回数ループにする。
- `くりかえす` はひらがな表記を正とする。
- v0.1 は `おしまい` で明示的に閉じる。インデントは可読性のために使い、意味上の block delimiter にはしない。

---

## E005 でかい / こまい

**ねらい**: 大小比較と条件接続。

```text
年齢 = 22

もし 年齢が 20 よりでかいん やったら
    "大人やん" っちゆう
おしまい
```

```text
残り = 2

もし 残りが 3 よりこまいん やったら
    "もうちょいやん" っちゆう
おしまい
```

**判定**: 採用候補

- `でかい / こまい` だけで `やったら` へ直結させず、`でかいん / こまいん` として受ける。
- Pyccha ソースでは lexer の境界を明確にするため、`でかいん やったら` のように空白を置く表記を標準にする。
- `〜ん` は比較・否定などの述語を条件節へつなぐ形として扱い、一般式すべてへ機械的に付ける規則にはしない。

---

## E006 真偽値

**ねらい**: `ほんとやん / うそやん` を値にできるか確認する。

```text
# v0.1 では次を真偽値リテラルとして採用しない
# 営業中 = ほんとやん
# 売り切れ = うそやん
```

**判定**: v0.1 では不採用

- `ほんとやん / うそやん` は発話としては面白いが、裸の値として代入すると断定・反応のニュアンスが強すぎる。
- v0.1 の最初の実装では真偽値リテラル自体を必須機能にしない。
- 将来、REPL の表示やエラーメッセージ、評価結果の見せ方に使う余地は残す。

---

## E007 AND

**ねらい**: `それと` を論理 AND として読む。

```text
もし 天気 == "晴れ" それと 曜日 == "日曜" やったら
    "出かけよ" っちゆう
おしまい
```

**判定**: 採用候補

- v0.1 の AND は `それと`。
- 自然文そのものではなく、Pyccha の論理結合語として意味を固定する。
- 優先順位は `それと` を `か` より強くする。

---

## E008 OR

**ねらい**: `か` を論理 OR として読む。

```text
もし 飲み物 == "コーヒー" か 飲み物 == "お茶" やったら
    "どっちも好き" っちゆう
おしまい
```

**判定**: 採用候補

- v0.1 の OR は `か`。
- `か` は `もし ... やったら` の条件式内部で論理 OR として解釈する。
- 疑問の `か` を一般構文として同時に導入しない。

---

## E009 NOT

**ねらい**: `やないん` を否定として使う。

```text
もし 売り切れ やないん やったら
    "まだあるやん" っちゆう
おしまい
```

**判定**: 採用候補

- v0.1 の NOT は前置き `not` の単純置換ではなく、`<対象> やないん` という後置の否定述語として扱う。
- `やない` ではなく、条件へ続く形として `やないん` を使う。
- 最初の parser では適用対象を単純な名前・原子的な式に限定し、複雑な式全体への NOT は後回しにする。

---

## E010 等しい / 違う

**ねらい**: 等値・非等値を無理なく書く。

```text
名前 = "山田"

もし 名前 == "山田" やったら
    "そうそう" っちゆう
おしまい

もし 名前 != "佐藤" やったら
    "佐藤さんやない" っちゆう
おしまい
```

**判定**: 採用候補

- `〜と同じ / 〜と違う` は説明文っぽくなり、コードとして長い。
- v0.1 は `== / !=` を残す。
- 方言化しないこと自体を正式な設計判断とする。

---

## E011 コメント

**ねらい**: コメントは方言化しない。

```text
# あとで名前は変える
名前 = "山田"

"こんにちは" っちゆう
```

**判定**: 採用

- コメントは `#`。
- コメント構文を日本語化しない。

---

## E012 「やけん」をどこに置くか

**ねらい**: 理由・前提表現を制御構文にする必要があるか確認する。

```text
雨が降っとるやけん、傘持っていき
```

**判定**: v0.1 構文では不採用

- `やけん` は理由・根拠をつなぐ表現として重要だが、`if` の別名にはしない。
- v0.1 では予約語にせず、文字列・メッセージ・将来の DSL 表現で使える語として残す。
- guard / reason 節など、意味が本当に合う用途が見つかった時点で再検討する。

---

## E013 「っちゃ」をどこに置くか

**ねらい**: Pyccha らしさの象徴を、無理に予約語へ押し込まない。

```text
"本人っちゃ" っちゆう
```

**判定**: v0.1 構文では不採用

- `っちゃ` は言語名・会話表現・REPL・エラーメッセージには活かせる。
- 断定、代入、文終端などの汎用予約語にはしない。
- 「Pyccha だから何でも `っちゃ` を付ける」という設計は避ける。

---

## E014 小さなまとめ例

**ねらい**: v0.1 の中核だけをまとめて読む。

```text
# 今日のおやつ
おやつ = "シロヤ"
個数 = 3

もし 個数が 0 よりでかいん やったら
    3回くりかえす
        おやつ っちゆう
    おしまい
ちごうたら
    "今日はなし" っちゆう
おしまい
```

**判定**: v0.1 実装用の基準標本

- `おしまい` がネストしても、明示的に block が閉じるため parser は単純に保てる。
- インデントは読みやすさのために推奨するが、最初の実装では構文意味を持たせない。
- `やけん`、構文としての `っちゃ`、`ほんとやん / うそやん` を外したことで、全体の役割分担が明確になった。

---

## v0.1 で固める構文

- [x] 出力: `<式> っちゆう`
- [x] 代入: `<名前> = <式>`
- [x] 条件分岐: `もし <条件> やったら`
- [x] else: `ちごうたら`
- [x] block 終端: `おしまい`
- [x] 回数ループ: `<整数>回くりかえす`
- [x] 等値 / 非等値: `== / !=`
- [x] 大小比較: `〜よりでかいん / 〜よりこまいん`
- [x] AND / OR / NOT: `それと / か / やないん`
- [x] コメント: `#`
- [x] `やけん`: v0.1 の予約語にしない
- [x] `っちゃ`: v0.1 の予約語にしない
- [x] `ほんとやん / うそやん`: v0.1 の真偽値リテラルにしない
