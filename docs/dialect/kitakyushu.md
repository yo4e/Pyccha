# 北九州弁ノート

この文書は、Pyccha の文法設計より先にある **「北九州弁として実際どう言うか」** を記録するためのノートです。

Pyccha の構文案は、この文書の内容を根拠として作ります。

## この文書の優先順位

- ここでは「プログラミング言語として便利か」より **北九州弁として自然か** を優先する。
- 文法に採用するかどうかは別文書で決める。
- 山田さんの実感と異なる記述があれば、遠慮なく直接書き換える。
- 「地域・世代・話者で違う」「意味は通るけど自分は言わない」も重要な情報なので残す。
- AIや資料から拾った表現は、山田さんが確認するまでは **仮** とする。

## 書き方

各項目には固定IDを付ける。文法設計側からはこのIDで参照する。

- **状態**: 仮 / 確認済み / 要注意 / 不採用
- **自然さ**: 自然 / 場面による / 意味は通る / 不自然 / 未確認
- **意味・ニュアンス**: 北九州弁として何を表すか
- **山田さんメモ**: 自由記述。ここを直接直してよい
- **Pyccha利用候補**: 言語側で何に使えそうか。これは方言事実ではなく設計案
- **例**: 実際に言いそうな文

## 2026-09-29 コード標本レビューで分かったこと

`docs/design/examples-v0.1.md` の E001〜E014 をコードとして読み直し、方言そのものとプログラミング構文の判断を改めて分離した。

- `でかい / こまい / やない` を条件へ続けるときは、`でかいん / こまいん / やないん` として受ける形を Pyccha 候補として維持する。
- ただし「〜ん」をあらゆる条件式へ付ける一般規則にはしない。
- `ほんとやん / うそやん` は会話の反応・断定としての色が強いため、Pyccha v0.1 の真偽値リテラルには使わない。これは方言として不自然という意味ではなく、**言語設計上の不採用**。
- `やけん` は理由・根拠を表す語として保持するが、v0.1 の制御構文にはしない。
- `っちゃ` も北九州弁らしさの重要な候補として保持するが、v0.1 の汎用予約語にはしない。
- `ちごうたら` と `おしまい` は、自然会話をそのまま再現する語というより、Pyccha の明示的な制御構文として採用候補にする。

### 状態の意味

- **山田案**: 山田さんから自然そうという候補が出た。まだ方言事実として固定しない。
- **仮**: 初期案。要確認。
- **設計判断**: 方言候補ではなく、Pyccha の実装・可読性のために選んだ表記。
- **確認済み**: 文脈・語順を含め、方言ノート上では採用してよい状態。
- **不採用**: 北九州弁として不自然、または Pyccha 用途に向かない。

## D001 「〜っちゃ」

- **状態**: 仮
- **自然さ**: 場面による
- **意味・ニュアンス**: 断定・説明・強調などの文末表現として使われる候補。
- **山田さんメモ**: Pycchaらしさの象徴ではあるが、何にでも付けると「なんちゃって方言」化しやすい。
- **Pyccha利用候補**: 言語名、REPL返答、エラーメッセージ、文字列中の会話表現。v0.1 の汎用予約語にはしない。
- **例**:
  - `本人っちゃ`

## D002 「〜やけん」

- **状態**: 仮
- **自然さ**: 場面による
- **意味・ニュアンス**: 理由・根拠・前提をつなぐ表現の候補。
- **山田さんメモ**: 単独の「けん」より「やけん」のほうが自然そう。`if` の別名にするのは意味がずれる。
- **Pyccha利用候補**: 将来の reason / guard / 前提表現。v0.1 では予約語にしない。
- **例**:
  - `雨が降っとるやけん、傘持っていき`

## D003 「〜やったら」

- **状態**: 仮
- **自然さ**: 場面による
- **意味・ニュアンス**: 条件を受ける接続表現の候補。
- **山田さんメモ**: 比較・否定の述語は `でかいん / こまいん / やないん` として受けてから `やったら` へ続ける形が自然そう。
- **Pyccha利用候補**: 条件分岐。v0.1 では `もし` と組み合わせて明示的に使う。
- **例**:
  - `もし 年齢が 20 よりでかいん やったら`
  - `もし 雨 やないん やったら`

## D004 「なん？」

- **状態**: 仮
- **自然さ**: 場面による
- **意味・ニュアンス**: 疑問・確認の終わり方の候補。
- **山田さんメモ**: 通常の条件式へ無理に入れず、対話的な場面で検討する。
- **Pyccha利用候補**: REPL の問い合わせ・確認表現。
- **例**:
  - `誰なん？`

## D005 「〜っちゆう」

- **状態**: 仮
- **自然さ**: 場面による
- **意味・ニュアンス**: 引用 + 発話。
- **山田さんメモ**: 「って言う」より「っちゆう」のほうが自然そう。
- **Pyccha利用候補**: 標準出力。自然言語での意味を完全にそのまま `print` と同一視せず、発話の語感を借りる。
- **例**:
  - `"こんにちは" っちゆう`

## D006 「ちごうたら」

- **状態**: 仮
- **自然さ**: 場面による
- **意味・ニュアンス**: 「違ったら」に相当する候補。
- **山田さんメモ**: else の位置に単独で置くのは Pyccha 側の人工的な使い方として割り切る。
- **Pyccha利用候補**: v0.1 の else。
- **例**:
  - `ちごうたら`

## D007 「おしまい」

- **状態**: 仮
- **自然さ**: 場面による
- **意味・ニュアンス**: 方言というより、終端を示す自然語。
- **山田さんメモ**: v0.1 は parser を単純に保つため、インデントだけにせず明示的な block terminator として使う。
- **Pyccha利用候補**: block terminator。
- **例**:
  - `おしまい`

## D012 / D013 / D018 「〜ん」で受ける形

- **状態**: 山田案
- **自然さ**: 候補として有力
- **意味・ニュアンス**: `でかい / こまい / やない` を条件へ続けるとき、`でかいん / こまいん / やないん` として受ける。
- **山田さんメモ**: `でかいん / こまいん / やないん` の形なら自然。
- **Pyccha利用候補**: 大小比較、後置否定を `やったら` へ接続する述語形。
- **例**:
  - `20 よりでかいん やったら`
  - `3 よりこまいん やったら`
  - `雨 やないん やったら`

## 方言ノートと文法仕様の関係

この文書で表現の意味や自然さが変更された場合、文法仕様側が古くなることがある。

**方言事実について矛盾した場合は、この文書を優先する。**

文法仕様は `docs/design/grammar-v0.1.md` で管理する。
