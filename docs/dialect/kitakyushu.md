# 北九州弁ノート

この文書は、Pyccha の文法設計より先にある **「北九州弁として実際どう言うか」** を記録するためのノートです。

Pyccha の構文案は、この文書の内容を根拠として作ります。

## この文書の優先順位

- ここでは「プログラミング言語として便利か」より **北九州弁として自然か** を優先する。
- 文法に採用するかどうかは別文書で決める。
- 山田さんの実感と異なる記述があれば、遠慮なく直接書き換える。
- 「地域・世代・話者で違う」「意味は通るけど自分は言わない」も重要な情報なので残す。
- AIや資料から拾った表現は、山田さんが確認するまでは **仮** とする。

## 書き方

各項目には固定IDを付ける。文法設計側からはこのIDで参照する。

- **状態**: 仮 / 確認済み / 要注意 / 不採用
- **自然さ**: 自然 / 場面による / 意味は通る / 不自然 / 未確認
- **意味・ニュアンス**: 北九州弁として何を表すか
- **山田さんメモ**: 自由記述。ここを直接直してよい
- **Pyccha利用候補**: 言語側で何に使えそうか。これは方言事実ではなく設計案
- **例**: 実際に言いそうな文

### 状態の意味

- **山田案**: 山田さんから自然そうという候補が出た。まだ固定仕様ではない。
- **仮**: 初期案。要確認。
- **標準語仮置き**: 方言候補がまだ分からないので、意味が分かる標準語を置いている。山田さんが北九州弁へ直すための下書き。
- **未確認**: 意味や役割そのものをまだ整理中。
- **確認済み**: 文脈・語順を含め、方言ノート上では採用してよい状態。
- **不採用**: 北九州弁として不自然、またはPyccha用途に向かない。

## 方言ノートと文法仕様の関係

この文書で表現の意味や自然さが変更された場合、文法仕様側が古くなることがある。

**方言事実について矛盾した場合は、この文書を優先する。**

文法仕様は `docs/design/grammar-v0.1.md` で管理する。
